# Overview

Cloud Native Computing Foundation — cloud-native tools organized by the CNCF landscape taxonomy.

* [AppDefinition and Development](appdefinitiondevelopment/) — Application build, CI/CD, databases, and messaging
* [CNAI](cnai/) — Data architecture and data science
* [Observability and Analysis](observabilityanalysis/) — Chaos engineering, cost optimization, and observability
* [Orchestration and Management](orchestrationmanagement/) — API gateway, service discovery, service mesh, and service proxy
* [Provisioning](provisioning/) — Automation, container registry, key management, and security
* [Runtime](runtime/) — Cloud native network, storage, and container runtime
* [Serverless](serverless.md) — Serverless computing
